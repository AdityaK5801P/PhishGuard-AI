# PhishGuard AI 🛡️

An AI-powered phishing detection web application that analyzes URLs and predicts whether they are legitimate or phishing using machine learning.

## Features (Planned)

- URL Analysis
- AI-Based Phishing Detection
- Risk Score
- Scan History
- Dashboard
- PDF Reports
- SSL & WHOIS Checks

## Tech Stack

- Frontend: React
- Backend: FastAPI
- Machine Learning: Scikit-learn
- Database: SQLite
- Deployment: Vercel & Render
